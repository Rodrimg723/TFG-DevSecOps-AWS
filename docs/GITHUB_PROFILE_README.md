> 1. Crea un nuevo repositorio público en GitHub con el **mismo nombre que tu usuario de GitHub** (por ejemplo, si tu usuario es `rodrigo-sys`, crea el repositorio `rodrigo-sys/rodrigo-sys`).

> 3. Abre ese `README.md` en GitHub, copia el contenido de abajo, reemplaza los datos entre `<...>` (como tu nombre de usuario de GitHub, LinkedIn, etc.) y guárdalo. ¡Tu perfil lucirá increíble!
